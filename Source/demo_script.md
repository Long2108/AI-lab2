# Demonstration Video Script

Record at least three runs of different sizes. Suggested cases:

```bash
python main.py Inputs/input-01.txt --method forward --show-kb --stats
python main.py Inputs/input-05.txt --method astar --show-kb --stats
python main.py Inputs/input-10.txt --method backward --show-kb --stats
python gui.py
```

In the recording:

1. Show the input file and point out grid, horizontal constraints, and vertical constraints.
2. Run the command from the terminal.
3. Explain key metrics: KB facts, CNF clauses, inferred facts, nodes, assignments, and frontier.
4. Show that the output file is saved in `Outputs/output-XX.txt`.
5. Include the final public YouTube or Google Drive URL in `Report.pdf`.
